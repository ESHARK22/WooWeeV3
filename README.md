# Fraud's Dungeon
To escape the dungeon, you must first find the one who does not lie. 


### About
This is a game where you are stuck in a dungeon filled with a group of people, and multiple doors. All but one door leads to death. All but one person lies. Find who tells the truth, and you will survive. 

This was built in Unity, for the [Brackeys Game Jam 2026.2](https://itch.io/jam/brackeys-16/rate/4944312), with a group of 3 friends, to get us familiar with the Unity Editor, for our A-Level coursework.


### Controls
* *WASD* for movement.
* *E* for interact.
